# GOD MODE Visual Review Checklist

Use this checklist for milestones that affect environment visuals, buildings, roads, terrain, lighting, vegetation, camera presentation, characters, animation, or effects.

## Environment visual gate

- Town reads clearly and attractively from Overview.
- Angled view has visible depth and terrain relief.
- Street view has believable scale and useful facade/sidewalk detail.
- Roads, intersections, sidewalks, pedestrian routes, lots, and public spaces are visually distinct.
- River/water is clearly visible and geographically legible.
- Terrain feels shaped rather than like a flat board.
- Forest/nature edge is compositionally distinct from town trees.
- Vegetation looks grouped and intentional rather than evenly scattered.

## Building visual gate

- Major functional categories are distinguishable by silhouette/massing.
- Housing has more than one coherent visual family.
- Commercial/civic buildings are not just recolored versions of the same house.
- Rooflines, entrances, facade depth, windows, canopies/awnings/porches or equivalent low-poly details create identity.
- Building spacing and street frontage create a believable small-town pattern.

## Lighting/material gate

- Day scene is bright enough to judge geometry and palette.
- Night/dawn scene remains readable without crushing the town into darkness.
- Water, road, sidewalk, soil/grass, roofs, walls, and vegetation separate clearly by value/material.
- Shadows support depth without hiding important forms.
- Palette feels cohesive rather than random.

## Polish gate

Flag the milestone if the scene is technically correct but still visibly prototype-like because of repetitive primitives, harsh unintentional edges, weak composition, unreadable geography, empty spaces, poor scale, or insufficient differentiation.

## Performance gate

- Repeated objects use shared/instanced geometry where practical.
- No unnecessary high-poly assets.
- Draw calls / triangle counts remain compatible with the MacBook Pro M2 / 8 GB target.
- Visual improvements do not move simulation authority into rendering.
