# M02 Known Limitations

- **One citizen only** — M03 adds twenty persistent founders.
- **Procedural art** — functional shared humanoid, not final character art ceiling.
- **No interiors** — indoor actions use invisible anchor points; no roof fade (VIS-003 deferred).
- **No economy** — eating/shopping satisfy needs directly without money or inventory (M04).
- **No memory/beliefs/social** — utility uses needs + schedule + personality noise only (M03+).
- **Simplified reflex** — temperature, health, psychological needs not yet modeled.
- **No third-party environment props** — M01 primitives + M02 corridor overlay only; CC0 kits approved for later targeted import.

M03 was **not** started in this milestone.
